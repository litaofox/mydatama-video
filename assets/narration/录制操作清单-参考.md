# 录制操作清单（第五章实机录屏逐镜对照）

> 对应分镜 24–30（视频 13:20–16:50）。录前通读一遍，正式录时按本清单操作即可，不用临场想。
> 约定：`▶` 点击动作；`⌨` 输入内容；`⏸` 停留给镜头看结果（至少 3 秒）。

---

## 0. 录制前 5 分钟环境准备

```powershell
# 项目根目录
docker compose down -v                    # 恢复空态（保证大屏全 0）
docker compose up -d --build              # 等 4 个容器 healthy
docker compose ps                         # 确认 STATUS 全部 healthy
bash scripts/smoke-test.sh                # 可选：先跑一遍确认全链路通（正式录制前需再次 down -v 造空态）
```

- 浏览器：`http://localhost:8090`，**Ctrl+F5 强刷**，关闭无关标签；
- 准备好两个浏览器 Profile 或一个普通窗口 + 一个无痕窗口（方便 admin/viewer 切换不互相挤掉登录）；
- 文件选择器提前打开一次 `samples/` 目录收藏到快速访问；
- OBS 开始录制后，先停 2 秒再操作（给剪辑留余量）。

---

## 镜 24（13:20–13:44）登录 + 403 + 大屏空态

1. ▶ 地址栏输入 `localhost:8090` 回车，⏸ 登录页 2 秒；
2. ⌨ admin / Admin@123，▶ 登录（或点页面上的 admin 快捷按钮）；
3. 自动进入大屏，**镜头扫过全 0 的计数卡**（资产 0 / 文件 0 / 数据集 0 / 产品 0）⏸；
4. 无痕窗口同样打开 8090，⌨ viewer / Viewer@123 登录；
5. ▶ 左侧菜单「用户管理」→ 页面出现 **403/无权限提示** ⏸ 3 秒；
6. 回到 admin 窗口继续。

## 镜 25（13:44–14:17）上传 0901 → 五阶段 → 质检 → 修复重跑

1. ▶ 左侧菜单「文件上传」；
2. ▶ 选择文件 `samples/vehicle_gps_20260901.csv`；
3. ⌨ 业务域 `TRANSPORT`；密级选择 **2（内部）**；
4. ▶ 上传，列表出现新记录后 ▶ 文件名进入「文件详情」；
5. **镜头对着五阶段时间线**：接收校验 → 清洗 → 标准化 → 脱敏 → 登记 逐格点亮（5 万行约 30–60 秒，可在剪辑时加速，旁白不停）；
6. 处理完成后 ⏸：质检指标（缺失≈2%、重复 1%、漂移 50、乱序 20）、敏感列清单（driver_phone / driver_idcard）；
7. ▶「一键修复」（或"修复并重跑"按钮），状态重新入队；
8. 重跑完成后 ⏸ 对比：坏行计数归零 / 质量分回升。

> 录制备份方案：处理等待时间较长，可先正常录前预先跑一遍生成好一个 READY 文件，录制时再上传一个小文件（如 fleet_info_sheet1.csv）讲流程，剪辑切到预跑文件的详情页展示指标。

## 镜 26（14:17–14:38）多模态三连传

依次上传三个（业务域均填 `TRANSPORT`，密级按括号）：

| 文件 | 密级 | 录屏看点（文件详情页） |
|---|---|---|
| `driver_notes.txt` | 2 | 文本处理结果：手机/邮箱/身份证命中计数 + 掩码预览 |
| `vehicle_photos.zip` | 2 | 图片张数、EXIF 剥离标记、缩略图 thumb |
| `dashcam_clips.zip` | 2 | 视频清单、ffmpeg 抽帧缩略图、元数据清除 |

每个文件详情页 ⏸ 2–3 秒即可，节奏快。

## 镜 27（14:38–15:10）资产目录 / 血缘 / 热力图

1. ▶ 左侧「资产目录」；⏸ 展示自动登记的资产列表（CSV/TXT/IMAGE/VIDEO 都在）；
2. 试一次筛选：模态选「结构化」或关键词搜 `vehicle`，⏸；
3. ▶ 打开 `vehicle_gps_20260901` 成品资产详情：镜头停在字段表格，指 **sensitive=是 + maskStrategy** 的行；
4. ▶「血缘图」页签/按钮：ECharts 力导图展示 raw → processed 节点与边，滚轮放大一次 ⏸；
5. ▶ 左侧「数据热力图」：域 × 日期格子出现颜色，鼠标悬停显示计数 tooltip ⏸。

## 镜 28（15:10–15:43）数据集 v1 / v2 / 对比

**v1**：

1. ▶ 左侧「数据集」→「构建数据集」；
2. ⌨ 名称 `驾驶行为样本集`；场景 `驾驶行为分析`；
3. 模态选「结构化」；业务域 ⌸ `TRANSPORT`；最低质量分保持默认（0 或 0.8）；确定；
4. 进入数据集详情 → ▶「生成版本」，⌸ changeNote `v1 首批 GPS 数据`；
5. ⏸ 版本一生成后展示三维报告：completeness / consistency / accuracy / overall_score（≥0.85）。

**补料 0902**：回「文件上传」上传 `vehicle_gps_20260902.csv`（GBK + 中文列名那个），等处理 READY，详情页可给 1 秒"列名同义词映射成功"的镜头。

**v2 + 对比**：

6. 回数据集详情 →「生成版本」，changeNote `v2 追加 0902`；
7. ▶ 版本对比（选 v1 与 v2）；⏸ added 列表出现 0902 资产、metricsDiff 指标差异。

## 镜 29（15:43–16:23）产品全流程 + 反面演示

**正面产品**：

1. ▶ 左侧「数据产品」→「创建产品」；
2. 模板选 **数据包 `tpl-data-package-v1`**；数据集选「驾驶行为样本集」、版本选 **v2**；
3. ⌸ 名称 `货运驾驶行为精算样本集`；编码保留自动建议或填 `PRD-20261001-001`；
4. 密级选 **2**（≥原料密级）；分类 `交通物流`；定价任选（如按月 1999）；
5. 说明书四要素都要填：来源说明、字段说明、更新频率（如"每月"）、交付方式（如"zip 下载"）；
6. ▶ 保存 → 在产品详情 ▶「提交配置」（DRAFT → CONFIGURED）；
7. ▶「生成」：⏸ 状态变 GENERATED，产物清单出现 zip / MANUAL_PDF；
8. ▶「说明书预览」：⏸ 八章结构，关闭；
9. ▶「合规校验」：⏸ **R1/R2/R3/R4 四绿**，状态 PASSED。（先不要登记，留给镜 30）

**反面产品（密级倒挂）**：

10. 先在「文件上传」上传 `unmasked_sample.csv`（业务域随意如 `RISK`，**密级选 3**），等 READY；
11. 若要让它进入数据集：可新建一个数据集（业务域与上传时一致）并生成版本；或复用不满足密级的现成版本；
12. 再建一个产品，密级故意选 **1（公开）**，其余照旧 → 生成 → 合规校验；
13. ⏸ **R1 SECRET_LEVEL 与 R2 SENSITIVE_MASKED 同时红色**，detail 显示"原料最大密级 3 高于产品密级 1 / 存在 N 个未脱敏敏感列"，状态 BLOCKED；
14. 点「登记」会被拦截（可演示一下错误提示）。

> 时间紧时反面演示可省略建数据集：直接用上面的产品把密级改为 1 重新校验，也能稳定触发 R1 红色。

## 镜 30（16:23–16:50）挂牌 + 大屏 + 审计

1. 回到正面产品详情 → ▶「登记」：⏸ 出现凭证号 `REG-20261001-XXXXXX`，状态 REGISTERED；
2. ▶「挂牌」：状态 LISTED；
3. ▶ 打开「数据大屏」（或顶部大屏入口）：⏸ 产品板块——挂牌数 +1、通过率、形态分布、最新产品列表；可原地等 10 秒展示轮询刷新；
4. ▶ 左侧「审计日志」：筛选模块/用户 admin，⏸ 列表中可见 LOGIN、文件上传、EXPORT/生成、登记、挂牌记录。
