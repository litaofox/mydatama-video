04RBAC：一个注解守住接口

@Aspect
@Component
public class RbacAspect {
    @Before("@annotation(p)")
    public void check(JoinPoint jp, RequirePerm p) {
        UserInfo user = UserContext.get();
        if (user == null) throw new BizException(ErrorCode.UNAUTHORIZED);
        if (user.getRoles() != null && user.getRoles().contains("admin")) return; // 管理员直通
        Set<String> own = user.getPermissions() == null ? Set.of()
                : new HashSet<>(user.getPermissions());
        for (String need : p.value()) {
            if (!own.contains(need)) throw new BizException(ErrorCode.PERM_DENIED);
        }
    }
}
// Controller 用法：@RequirePerm("prod:product:export")

04ComplianceEngine：合规四规则（真实代码节选）

String batchNo = "BC" + CodecUtil.today() + CodecUtil.randomHex(4).toUpperCase();
List<RuleResult> results = new ArrayList<>();
results.add(ruleSecretLevel(product, snapshots));       // R1 原料最大密级 ≤ 产品密级
results.add(ruleSensitiveMasked(snapshots, items));     // R2 敏感列必须有 maskStrategy
results.add(ruleQualityThreshold(qualityReport, cfg));  // R3 overall_score ≥ 0.85
results.add(ruleManualComplete(manualMeta));            // R4 说明书四要素非空
for (RuleResult r : results) { complianceCheckMapper.insert(toCheck(r, batchNo)); }
product.setStatus(results.stream().allMatch(r -> r.passed) ? "PASSED" : "BLOCKED");

每条结果携带人可读 detail，例如 "原料最大密级 3 高于产品密级 1"——反面演示以密级倒挂稳定触发 R1 亮红，产品被 BLOCKED。

04状态机：非法跳转直接拒绝

public void configure(Long id) {
    Product product = mustGet(id);
    assertStatus(product, "DRAFT");          // 只能从草稿提交配置
    if (product.getSecretLevel() < maxSnapshotSecretLevel(items))
        throw new BizException(600008, "产品密级不能低于原料密级");
    product.setStatus("CONFIGURED");
}
public Product register(Long id) {
    Product product = mustGet(id);
    if (!"PASSED".equals(product.getStatus()))
        throw new BizException(ErrorCode.REGISTER_NOT_ALLOWED);
    product.setRegNo("REG-" + CodecUtil.today() + "-" + CodecUtil.randomDigits(6));
    product.setStatus("REGISTERED");
}
